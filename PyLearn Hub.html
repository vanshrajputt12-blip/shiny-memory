Variables in Python

A variable is a name that points to a value stored in memory. Python figures out the type automatically, so you don't declare it up front — this is why the language reads so cleanly for beginners.

age = 25
name = "Ava"
is_student = True

Common mistake: reusing a built-in name like list or str as a variable, which quietly shadows the built-in.

Mini exercise: create three variables for a book's title, price, and whether it's in stock, then print all three.

Source & further reading: docs.python.org — official tutorial
